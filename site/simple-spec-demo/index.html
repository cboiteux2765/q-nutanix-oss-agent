      Governed self-evolution

      The agent improves by changing a versioned harness around a fixed model: lessons, memories, skill cards and subagent specs. It never edits its own core. This follows Prime Agent's Continual Harness and /refine: small, evidence-backed updates with history and rollback. Here every update also has to pass explicit gates.

      What this demo does vs. the Python server

      This page plays a recorded run and simulates the benchmark replay with fixed rules, so you can see how the gates behave. In agent/learning.py the comparison is real: baseline and candidate prompts run on the same evidence and a critic scores them. To make that governance meaningful, add a frozen benchmark of pinned evidence snapshots. Today's scenarios are regenerated each run, so scores can't be compared across runs.
